# ターゲット1800 究極反復学習システム

英単語を「覚えた」まで回し切るための学習サイト。ビルド不要の HTML / CSS / JS だけで動きます。

## 開き方

- いちばん簡単：`index.html` をダブルクリック（Chrome / Edge 推奨）
- ローカルサーバーで：`python -m http.server 8440 --directory C:/target1800` → http://localhost:8440

学習データはブラウザの localStorage（キー `t1800:v1`）に保存されます。
ファイルで開いた場合とサーバーで開いた場合は別の保存場所になるので、どちらかに決めて使ってください。

## 単語帳（設定・データ → 使う単語帳）

| 単語帳 | 中身 |
|---|---|
| ターゲット1800（既定） | `js/words-book.js`。持ち主の「中学英単語ターゲット1800 4訂版 単語一覧」PDFから取り込んだ1800語（番号・英単語・意味）。**個人の学習用なので公開・配布しない** |
| 独自600語 | `js/words-1.js` `js/words-2.js`。このアプリ用に独自に作った語（例文・類義語つき） |
| マイ単語帳 | 自分で貼り付けて取り込む語 |
| 1800＋マイ単語帳 | 上の2つを合わせたもの |

ターゲット1800の分け方：

- Part 1 基礎（No.1–600）／Part 2 標準（No.601–1200）／Part 3 発展（No.1201–1800）
- Section は100語ごとの18区切り（Section 1 = No.1–100 … Section 18 = No.1701–1800）
- 品詞は意味の最初の【】から（冠詞・間投詞は「その他」）
- 独自600語と重なる語（約240語）には、独自に作った例文・類義語・対義語・派生語を添えている（意味は一覧のまま）
- May（5月）と may、Miss と miss のように小文字で同じになる語は、別の語として記録する

元PDFの誤記は、学習用に正しい綴りへ直しています：TRUE→true(405)、Community→community(890)、dicision→decision(1144)、fingar→finger(1416)、calcurate→calculate(1545)、worse→worst(1666、意味が最上級)、dark→bark(1782、意味が「ほえる」)。
意味の誤記「コミュニケーションをおる」(821)は「とる」に、PDFで途中が切れていた in(5)・of(9)・anywhere(1534) の意味は補っています。

書籍の番号どおりに自分で取り込む場合は「設定・データ → マイ単語帳を取り込む」に貼り付けます。

```
番号, 英単語, 意味, 品詞, 例文, 例文訳, 類義語, 対義語, 派生語
1, create, ～を創造する, 動, She [created] a new logo., 彼女は新しいロゴを作った。, make, destroy, creation
```

- 区切りはタブ・カンマ・縦棒（|）のどれでも可。最低限「番号・英単語・意味」
- 例文の見出し語を `[ ]` で囲むと、意味だけ表示モードで穴埋めになる
- 番号から Part（1–800 / 801–1500 / 1501–）と Section（100語ごと）を自動で組む
- 学習記録は英単語ごとに保存されるので、単語帳を切り替えても消えない

## 機能

| 画面 | 中身 |
|---|---|
| ホーム | 全体の習得率・品詞別・Part/Section 別の進捗、学習ヒートマップ。Section から直接学習開始 |
| 学習 | 範囲（Part / Section / タグ / 状態 / 番号）× モード（意味だけ表示 / A 手書き / B 4択 / B 口頭 / ディクテーション） |
| 復習 | 間隔反復で「今日の復習」を抽出、7日間の予定、要復習リスト（苦手克服ループ） |
| タイムアタック | 60秒・4択。5/10/20/30 コンボで演出が変化。間違えた語は要復習へ |
| ながら聴き | 英語×回数 → 日本語 → 例文 → シャドーイングの間 を自動再生 |
| 単語一覧・タグ | 検索・絞り込み・一括タグ付け、タグごとの模試 |
| 設定・データ | JSON 書き出し／読み込み、マイ単語帳、音声・テーマ設定 |

ポモドーロ（25分/5分、4回ごとに長い休憩）は上部バーに常駐し、学習中は学習画面のヘッダーに入ります。

## 文法・入試対策（js/grammar.js・js/grammar-data.js）

中1〜中3の文法26単元・1000問（1単元38〜39問）。例文・和訳・選択肢・各単元のポイント解説はこのアプリ用に独自に作成し、使っている語はすべてターゲット1800の収録語（活用形を含む。人名・地名は除く）。

| 学年 | 単元 |
|---|---|
| 中1 | be動詞と一般動詞／代名詞／名詞の複数形・冠詞／疑問詞／三単現のs／現在進行形／助動詞can／命令文・感嘆文／過去形 |
| 中2 | be動詞の過去形・過去進行形／未来（will・be going to）／助動詞（must・have to・should・may）／不定詞／動名詞／文型（SVOO・SVC・SVOC）／比較／There is・are／接続詞／受動態 |
| 中3 | 現在完了・現在完了進行形／間接疑問文／不定詞の応用／分詞の形容詞的用法／関係代名詞／仮定法／原形不定詞 |

- 出題形式：**穴埋め**（4択）／**並べ替え**（和訳を見て語をタップ）／**和文英訳**（入力して自動採点。大文字小文字・句読点・短縮形の違いは同じとみなし、1〜2文字のミスは「おしい」。別解は「正解にする」で直せる）／**英文和訳**（訳を考えてから答えを見て自己採点）／ミックス
- 出題範囲：単元ごと、ランダム（学年・形式・問題数を選ぶ）、間違えた問題、**入試実戦テスト**（ランダムな20単元から1問ずつ、穴埋め8・並べ替え5・英訳4・和訳3）
- 解いたあとに正解の文・和訳・単元のポイント・文中の収録語（タップで単語カード）を表示
- 成績は `gram`（問題ごとの直近の得点）に、スコアランクは単元×形式・ランダム条件・実戦テストごとに `ranks.gram` に残す
- 問題の書式：`#U|単元ID|学年|単元名|サブタイトル|ポイント（／で改行）` の下に `英文（{正解|誤り|誤り|誤り}）|和訳` を1行ずつ

## 学習ランク（段位・js/rank.js の `Level`）

全体の学習量に比例し、休むと下がる段位（10級〜1級、初段〜十段の20段階）。

- 1回答で1pt、正解ならさらに1pt（単語・文法・タイムアタックすべての回答）
- 学習しなかった日は、次の日に −3%。続けて休むほど −5%、−7% … と大きくなり、最大 −15%/日
- 記録（`stats.daily`）から毎回計算し直す。ホームのカードに段位・次の段位まで・直近30日の推移（休んだ日に印）・「今日やらないと明日 −◯pt」、サイドバーにも段位を表示

## スコアランク（全7段階・js/rank.js）

| ランク | 学習スコア | タイムアタック |
|---|---|---|
| 初（銅） | 50点以上 | 1,000点以上 |
| 習（銀） | 60点以上 | 2,000点以上 |
| 得（金） | 70点以上 | 3,500点以上 |
| 熟（翠） | 80点以上 | 5,500点以上 |
| 達（蒼） | 90点以上 | 8,000点以上 |
| 傑（紅） | 95点以上 | 11,000点以上 |
| 天（虹） | 100点 | 15,000点以上 |

- 学習スコア＝1回目の答えの平均（覚えた 1・まだ怪しい 0.5・忘れた 0）を100点満点にしたもの。10語以上を最後まで解いたときだけ判定する（途中終了は判定なし）
- 単語帳ごと・範囲（Section / Part / タグ / 品詞 / 番号 / すべて）ごとに最高ランクを `ranks.study` `ranks.ta` に残す。今日の復習・要復習リスト・状態別・「つまずいた語をもう一周」は中身が毎回変わるので記録しない
- ホームに獲得ランクの棚と各 Section カードの徽章、タイムアタックのメニューに範囲ごとの最高ランク、結果画面に獲得演出。「ランク表」ボタンで基準を表示
- 徽章は亀甲（六角形）の紋をSVGで描いている。しきい値は `Rank.STUDY_TH` / `Rank.TA_TH`

## 間隔反復の計算（js/core.js の `SRS`）

- 覚えた：間隔 1 → 3 → 間隔×易しさ係数（初回で覚えたは4日）。係数 +0.1（上限3.0）
- まだ怪しい：翌日に再出題、係数 −0.15、要復習リストへ
- 忘れた：当日中に再出題、係数 −0.2、要復習リストへ
- 定着度 = 正答率（(正答+1)/(回答+2)）× 0.9^(直近の正解からの日数 ÷ 間隔)

## 音声について

Web Speech API を使うので、英語の音声が端末に入っている必要があります。
Windows で英語が読まれない場合は、Chrome（Google の英語音声）か Edge で開くか、
「設定 → 時刻と言語 → 音声 → 音声を追加」で「英語（米国）」を追加してください。
